# Trilha PCMG — Plataforma de Estudos

Plataforma pessoal para organizar a preparação para Investigador da Polícia Civil de Minas Gerais (PCMG).

## Funcionalidades iniciais
- Painel de progresso e indicadores.
- Cronograma semanal com duas matérias por dia.
- Um checkbox por matéria/sessão, com progresso salvo no navegador.
- Biblioteca inicial de disciplinas e tópicos de referência.
- Registro manual de questões, acertos e tempo estudado.
- Sugestões de revisão em 1, 7 e 30 dias.
- Atalho para o TEC Concursos.
- Layout responsivo para computador e celular.

## Executar localmente
Requer Node.js 20 ou superior.

    npm install
    npm run dev

## Publicar na Vercel
Importe o repositório na Vercel. Framework: Vite; build: npm run build; diretório de saída: dist. A versão inicial não exige variáveis de ambiente.

## Observação sobre o conteúdo
Esta é a primeira versão funcional do organizador. A trilha de assuntos é uma estrutura de referência, não uma reprodução garantida de um futuro edital. Confira sempre o edital vigente e a legislação em fontes oficiais. PDFs completos, videoaulas, simulados e integração externa deverão ser construídos e revisados em etapas posteriores.
